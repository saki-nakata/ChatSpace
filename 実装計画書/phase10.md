## フェーズ10 — UX拡張

**状態: 未着手**

必須機能要件そのものではないが、プロトタイプで実際の使用感を確認しながら価値が確認できた拡張機能を実装する(README.md「上記の要件に加えて」節参照)。

### 実装対象

- [ ] 未読区切り線(スコープを開いた瞬間の既読位置を基準に固定表示)
- [ ] 検索結果・通知からのジャンプ・ハイライト(該当メッセージを画面中央にスクロールし背景色フェードアウト。スレッド返信もジャンプ対象、S-07を自動的に開く)
- [ ] タイピングインジケーター表示(フェーズ4で実装済みのSTOMPイベントをUIに反映)
- [ ] オンライン/オフラインのプレゼンス表示(フェーズ4・9-Dで実装済みの基盤をUIに反映)
- [ ] ブラウザ通知(Web Push / Notification API)・未読件数のタブタイトル表示
- [ ] スレッド返信の通知UI(フェーズ5で実装済みの`THREAD_REPLY`通知をパネルに反映)
- [ ] ワークスペースからの自主退出(フェーズ2で実装済みAPIをUIから呼べるようにする)

### 先に書くテスト

このフェーズは主にUI機能のため、認可クリティカルテストの新規追加は無い。既存の受け入れテスト(AUTH-N10〜N17、AUTH-N27〜N29等)がUI経由でも成立することを手動確認する。

### 対象外(本フェーズでは扱わない)

- 音声通話等、CLAUDE.mdで対象外と明記された機能(ボイスチャンネル)

### 確認方法

```bash
cd apps/api-java && ./gradlew bootRun --args='--spring.profiles.active=dev,seed'
cd apps/web-next && pnpm --filter @chatspace/web-next dev
# 複数ブラウザタブでタイピング・プレゼンス・通知・未読区切り線を手動確認
```
